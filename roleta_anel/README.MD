Roleta Distribuida em Anel
Descricao do Projeto
Trabalho pratico de Redes de Computadores desenvolvido para a UFPR
Implementacao de um jogo de roleta distribuido em anel de 4 maquinas usando sockets UDP sem servidor central e sem broadcast

Estrutura de Pastas
include contem os cabecalhos h do protocolo rede e jogo

src contem os arquivos cpp com a implementacao da rede do jogo e main

docs contem a documentacao do protocolo e relatorio
